# TIS Academy — BCS Preparation & MCQ Platform (Mobile App / PWA)

**তৈরি ও পরিচালনায়:** তারিকুল ইসলাম (সুমন) · MSc Mathematics · [TIS Academy (YouTube)](https://www.youtube.com/@tis.academy24)

BCS প্রিলিমিনারি প্রস্তুতির জন্য একটি সম্পূর্ণ অ্যাপ (১০ম–৫০তম BCS)। এটি একটি **PWA (Progressive Web App)**। GitHub-এ আপলোড করলে **PC/Laptop-এ লিংক দিয়ে সরাসরি LIVE চলবে**, আর **মোবাইলে অ্যাপের মতো ইনস্টল হবে** (হোম স্ক্রিনে আইকন, ফুল-স্ক্রিন, ইন্টারনেট ছাড়াও চলে)।

---

## ১. GitHub-এ আপলোড করে LIVE করার নিয়ম (কোডিং লাগবে না)

1. **github.com**-এ লগইন করুন (অ্যাকাউন্ট না থাকলে ফ্রি অ্যাকাউন্ট খুলুন)।
2. ডান পাশে উপরে **+ → New repository** চাপুন।
   - Repository name: `bcs-prep` (বা আপনার পছন্দের নাম)
   - **Public** নির্বাচন করুন (ফ্রি GitHub Pages-এর জন্য দরকার)
   - **Create repository** চাপুন।
3. নতুন রিপোজিটরি পেজে **"uploading an existing file"** লিংকে ক্লিক করুন।
4. ZIP আনজিপ করে **`bcs-app` ফোল্ডারের ভেতরের সব ফাইল ও ফোল্ডার** (`index.html`, `sw.js`, `manifest.webmanifest`, `assets`, `css`, `js`, `icons`, `templates`, `README.md`) একসাথে টেনে (drag & drop) আপলোড বক্সে ছেড়ে দিন।
   > ⚠ বাইরের `bcs-app` ফোল্ডারটি নয়, **ভেতরের জিনিসগুলো** আপলোড করুন, যাতে `index.html` রিপোজিটরির মূল (root) জায়গায় থাকে।
5. নিচে **Commit changes** চাপুন।
6. রিপোজিটরির **Settings → Pages** এ যান।
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` এবং ফোল্ডার `/ (root)` → **Save**
7. ১–২ মিনিট পর পেজের উপরে লিংক দেখাবে:
   **`https://<আপনার-username>.github.io/bcs-prep/`**
   এই লিংক যেকোনো PC, Laptop বা মোবাইলের ব্রাউজারে খুললেই অ্যাপ LIVE চলবে। ✅

## ২. অ্যাপ হিসেবে ইনস্টল করুন

| ডিভাইস | কীভাবে |
|---|---|
| **Android (Chrome)** | লিংক খুলুন → উপরে **⤓ Install app** বাটন চাপুন, অথবা ⋮ মেনু → **Install app / Add to Home screen** |
| **iPhone / iPad (Safari)** | লিংক Safari-তে খুলুন → **Share (□↑)** → **Add to Home Screen** |
| **PC / Laptop (Chrome / Edge)** | অ্যাড্রেস বারের ডানে **Install (⊕)** আইকন চাপুন, অথবা **⤓ Install app** বাটন |

ইনস্টলের পর অ্যাপটি আলাদা উইন্ডো/অ্যাপ হিসেবে খুলবে এবং **ইন্টারনেট ছাড়াও চলবে**।

## ৩. (ঐচ্ছিক) Android APK ফাইল বানানো, কোডিং ছাড়া

1. **https://www.pwabuilder.com** এ যান।
2. আপনার GitHub Pages লিংক দিন → **Start**।
3. **Package For Stores → Android → Generate Package** → ZIP ডাউনলোড করুন।
4. ভেতরের `.apk` ফাইল ফোনে ইনস্টল করুন (Settings-এ "Install unknown apps" চালু করতে হতে পারে)। একই প্যাকেজ দিয়ে Google Play Store-এও দেওয়া যায়।

## ৪. আপডেট দেওয়ার নিয়ম

1. GitHub-এ পরিবর্তিত ফাইল আবার আপলোড করুন (একই নামের ফাইল replace হবে)।
2. **`sw.js`** ফাইলের প্রথম দিকের `VERSION` লাইনটি বদলান, যেমন `'tis-bcs-prep-v3.0.0'` → `'tis-bcs-prep-v3.0.1'`।
3. ব্যবহারকারীর অ্যাপে **"A new version is available → Update now"** বার্তা আসবে। পরীক্ষা চলাকালে কখনো জোর করে রিলোড হবে না।

## প্রশ্নব্যাংক সম্পর্কে (গুরুত্বপূর্ণ)

- অ্যাপের সাথে থাকা **১৬৭টি প্রশ্ন নমুনা (Sample)।** এগুলো BCS সিলেবাসের ধাঁচে লেখা, তবে কোনো নির্দিষ্ট BCS-এর অফিসিয়াল প্রশ্ন বলে দাবি করা হয়নি। সবখানে কমলা **Sample** ব্যাজ দেখায়।
- আসল বিগত BCS প্রশ্ন যোগ করতে: **Settings & Data → Import questions** (CSV/JSON; টেমপ্লেট `templates/` ফোল্ডারে)। প্রতিটি প্রশ্নে `bcs` নম্বর দিন। অফিসিয়াল উৎসের সাথে মিলিয়ে নিশ্চিত হলে তবেই `verified` = `true` দিন।
- Import করা প্রশ্ন একই ব্রাউজারে সেভ থাকে। সবার জন্য স্থায়ীভাবে যোগ করতে চাইলে প্রশ্নগুলো `js/data/questions.sample.js` এর মতো একটি ফাইলে রেখে GitHub-এ আপলোড করুন।

## ডেটা সংরক্ষণ

- সব ফলাফল **আপনার ডিভাইসের ব্রাউজারে** (localStorage) সেভ থাকে। অ্যাপ বন্ধ করলেও মুছে যায় না, আর অ্যাপ ব্রাউজারকে ডেটা স্থায়ীভাবে রাখার অনুরোধও করে।
- PC আর মোবাইলের ডেটা আলাদা। এক ডিভাইস থেকে অন্যটিতে নিতে **Settings → Export backup** করে অন্য ডিভাইসে **Import backup** করুন।

## ফিচার সংক্ষেপে

- **Exam Mode:** BCS নির্বাচন বাধ্যতামূলক; টাইমার, প্রশ্ন প্যালেট, Mark for review, নেগেটিভ মার্কিং (+1/−0.50, পরিবর্তনযোগ্য), রিফ্রেশ করলেও পরীক্ষা চলতে থাকে, সময় শেষে অটো সাবমিট। পরীক্ষার সময় মোবাইলের স্ক্রিন বন্ধ হয় না।
- **Result:** নম্বর, শতকরা, accuracy, সময়, বিষয়ভিত্তিক ফল; প্রতিটি প্রশ্নের সঠিক/ভুল (সবুজ/লাল) ও ব্যাখ্যা; All / Correct / Incorrect / Unanswered ফিল্টার।
- **Practice Mode:** টাইমার নেই; উত্তর ও ব্যাখ্যা আলাদা বাটনে, নিজে চাইলে তবেই দেখা যায়; একই প্রশ্ন বারবার দেখলে একাধিক attempt গণনা হয় না; **Retry question** অপশন আছে।
- **Analysis / Progress:** বিষয়ভিত্তিক ও টপিকভিত্তিক accuracy, দুর্বল/শক্তিশালী বিষয়, পরামর্শ, পরীক্ষাভিত্তিক উন্নতির গ্রাফ, BCS-ভিত্তিক তুলনা, পারফরম্যান্স রিপোর্ট (HTML/PDF), CSV এক্সপোর্ট।
- **মোবাইল অ্যাপ:** নিচে ট্যাব বার, অফলাইন, হোম-স্ক্রিন আইকন, ডার্ক মোড, iPhone notch সাপোর্ট।

## নাম, ছবি ও লিংক পরিবর্তন

- লেখকের নাম, ডিগ্রি, ইউটিউব/ফেসবুক/হোয়াটসঅ্যাপ/গিটহাব লিংক: **`js/views/profile.js`** ফাইলের শুরুতে `PROFILE` অংশে আছে।
- ছবি: `assets/profile.jpg` (বর্গাকার ছবি দিয়ে একই নামে replace করুন)। লোগো: `assets/tis-logo.jpg`।
- অ্যাপ আইকন: `icons/` ফোল্ডার।
- কিছু বদলালে `sw.js` এর `VERSION` বাড়াতে ভুলবেন না।

## ফাইল কাঠামো

```
index.html               অ্যাপের মূল পেজ
manifest.webmanifest     অ্যাপের নাম, আইকন, রং (ইনস্টলের জন্য)
sw.js                    Service worker — অফলাইন ও আপডেট
icons/                   অ্যাপ আইকন
assets/                  লেখকের ছবি ও TIS Academy লোগো
js/views/profile.js      লেখক পরিচিতি কার্ড (নাম, ছবি, লিংক)
css/styles.css           ডিজাইন (লাইট/ডার্ক, মোবাইল)
js/pwa.js                ইনস্টল বাটন, আপডেট বার্তা, স্ক্রিন জাগিয়ে রাখা
js/app.js                রাউটার ও থিম
js/core/*.js             স্টোরেজ, প্রশ্নব্যাংক, পরিসংখ্যান, চার্ট
js/views/*.js            Dashboard, Exam, Practice, Bank, Analysis, Progress, Settings
js/data/                 কনফিগ ও নমুনা প্রশ্ন
templates/               প্রশ্ন import টেমপ্লেট
```

## কম্পিউটারে লোকালি চালাতে

`index.html` ডাবল-ক্লিক করলেই চলবে। ইনস্টল ও অফলাইন ফিচারের জন্য অবশ্য `https://` লিংক (GitHub Pages) বা লোকাল সার্ভার লাগবে: ফোল্ডারে `python -m http.server` চালিয়ে `http://localhost:8000` খুলুন।
